## 一、开服前：配置怎么选

帕鲁是生存建造游戏，服务端吃 CPU 单核性能和内存，带宽不是大头。按下表对号入座：

| 人数 | 推荐配置 | 说明 |
|---|---|---|
| 2-4 人 | 4 核 4G | 亲友开黑，够用且便宜 |
| 4-8 人 | 4 核 8G | 最均衡的一档，mod 多了也扛得住 |
| 8 人以上 | 8 核 16G | 常驻服、公服级别 |

小贴士：带宽选 5-10M 即可；地域选离兄弟们近的节点，延迟比配置更影响体验。

### 一键开服是什么

腾讯云轻量云游戏服把开服压缩到了几分钟：游戏服务端**预装**，购买后创建实例即开服，网页面板管理配置、存档、mod。目前支持幻兽帕鲁（Java 1.21.4 正式版）、饥荒、七日杀、夜族崛起、求生之路 2、雾锁王国、泰拉瑞亚、英灵神殿等热门游戏，一款通关随时切换。

适合人群：想开服但不想碰命令行的兄弟；想稳定运行不想折腾运维的服主。

## 三、一键开服步骤

1. 进入轻量云游戏服活动页，选游戏（幻兽帕鲁）和规格（4 核 4G 或 4 核 8G）
2. 下单创建，等服务端初始化完成（通常几分钟）
3. 游戏面板确认服务器状态为「运行中」
4. 幻兽帕鲁客户端 → 加入服务器 → 输入 IP:端口，开黑
5. 以后管存档、装 mod、改设置，都在网页面板操作，不用连服务器

## 四、常见问题

**Q：存档在哪？换服会丢吗？**
在游戏面板里可以查看和备份存档。换机器/换游戏前先在面板备份存档文件，导入新服即可继承进度。

**Q：能装 mod 吗？**
能。面板提供 mod 管理；部分 mod 需要服务端和客户端一致，让兄弟们都装同一个 mod 列表再进服。

**Q：掉线/卡顿怎么办？**
先看面板的资源监控：CPU 长期 90%+ 就升配；延迟高就换离大家更近的地域；频繁掉线检查服务端版本是否和客户端一致。

**Q：新客有什么优惠？**
游戏服专区有新客首单特惠；另外官方代金券礼包（最高抵 36 个月订单）也可用于新购，以官网活动为准。

**Q：和手动部署比，一键开服限制在哪？**
游戏列表固定（持续上架中）、部分深层参数需要在面板里改。如果你要跑大量自定义 mod 或改服务端源码，还是手动部署更自由。

## 五、手动部署存档备份脚本

用一键开服或者面板管理的话，以下脚本供手动部署的服主参考——自动打包存档到本地：

```bash
#!/bin/bash
# backup-palworld-save.sh —— 打包帕鲁存档并留时间戳
SAVE_DIR="$HOME/Palworld/Saved"          # 按实际路径修改
BACKUP_DIR="$HOME/palworld-backups"
mkdir -p "$BACKUP_DIR"
TS=$(date +%Y%m%d-%H%M%S)
tar -czf "$BACKUP_DIR/palworld-save-$TS.tar.gz" -C "$SAVE_DIR" .
echo "备份完成: $BACKUP_DIR/palworld-save-$TS.tar.gz"
# 保留最近 10 份，删除更早的
ls -t "$BACKUP_DIR"/palworld-save-*.tar.gz | tail -n +11 | xargs -r rm
```
